Playing on wasmarcade.com (Vice City, Minecraft)

  1. Keep the laptop program running and open the game in the browser on this laptop.
  2. Move the laptop's mouse pointer over the game window and leave it there (the phone moves it from then on).
  3. Click once inside the game (or tap R2 on the phone, which is the left mouse button). That captures the mouse, so the look stick can turn the camera.
  4. ESC on the phone releases the mouse; click inside the game again to capture it.
  5. If an action is on the wrong key, press KEYS on the phone, tap the button, pick the new key.
